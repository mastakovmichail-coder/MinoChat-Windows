MINOCHAT ДЛЯ WINDOWS (настоящее приложение, не сайт в браузере)

СПОСОБ 1 - у себя на компьютере (проще всего)
  1. Установите Node.js LTS: https://nodejs.org
  2. Дважды щёлкните build.bat (он сам попросит права администратора - нажмите "Да"). Первый раз качает около 200 МБ и собирает 5-10 минут.
  3. Готовые файлы появятся в папке dist:
       MinoChat-Setup-3.0.0.exe         - установщик (ярлыки на рабочем столе и в Пуске)
       MinoChat-Portable-3.0.0.exe - запускается без установки

СПОСОБ 2 - в облаке GitHub (если не хочется ставить Node)
  Загрузите эту папку в репозиторий GitHub -> вкладка Actions -> Build MinoChat EXE -> Run workflow
  -> через несколько минут скачайте MinoChat-Windows из Artifacts.

ЧТО УМЕЕТ
  - Свое окно с логотипом MinoChat, значок в трее (крестик сворачивает в трей).
  - Мигание в панели задач и число непрочитанных в подсказке трея.
  - Звонки, показ экрана, микрофон, камера, уведомления Windows.
  - Автозапуск с Windows: правый клик по значку в трее.
  - Интерфейс и все функции те же, что на сайте. Чтобы обновить интерфейс,
    положите новый public/ в папку www и пересоберите.
  - Одновременно запускается только одна копия.

ВАЖНО
  - Вход через Google в приложении может не работать (Google блокирует вход во встроенных окнах).
    Входите по почте и паролю.
  - Windows SmartScreen / антивирус могут ругаться на неподписанный exe - это нормально для
    программ без платного сертификата. Нажмите "Подробнее -> Выполнить в любом случае".
  - Сервер и база те же (Firebase проект speeky-a0653), нужен интернет.


=== INNO SETUP УСТАНОВЩИК НАСТОЯЩЕГО ПРИЛОЖЕНИЯ (3.4) ===
Папка installer\ - красивый установщик. Он ставит именно Electron-приложение MinoChat.exe (не сайт).
Локально: дважды щёлкните build-installer.bat (нужны Node.js и Inno Setup 6) -> installer\Output\MinoChat-Setup.exe
Через GitHub: загрузите проект (как раньше) - во вкладке Actions в артефакте MinoChat-Installer будет MinoChat-Setup.exe.

ЕСЛИ АНТИВИРУС РУГАЕТСЯ (ложное срабатывание):
Файл не подписан платным сертификатом, поэтому Windows/антивирусы осторожничают. Это не вирус.
 1. Защитник Windows -> Защита от вирусов -> Управление настройками -> Исключения -> добавить папку установки MinoChat и файл установщика.
 2. Восстановите файл из Карантина (Журнал защиты -> Разрешить на устройстве).
 3. Отправьте файл как ложное срабатывание: https://www.microsoft.com/wdsi/filesubmission (выбрать "Я считаю, что файл не вреден"). Обычно снимают за 1-2 дня.
 4. Чем меньше людей скачали файл, тем подозрительнее. Полностью убирает проблему только цифровая подпись (платный сертификат).
